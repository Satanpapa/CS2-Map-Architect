# CS2 Map Architect

Локальная мастерская для проектирования оригинальных соревновательных карт Counter-Strike 2 (5v5, Defuse).

## Состояние репозитория

Этот репозиторий был создан пустым. Первая фаза проекта пока передана отдельным исходным архивом в текущем разговоре; её файлы ещё не импортированы в GitHub. Ветка `phase-2-route-planning` содержит добавления PHASE 2, которые рассчитаны на базовые модели, валидатор и SVG-рендерер из PHASE 1.

**Не сливать эту ветку в main до импорта PHASE 1.** Иначе пакет не будет самодостаточным.

## Реализация PHASE 2 в этой ветке

- Dijkstra: кратчайший маршрут по графу зон.
- Yen: до K кратчайших простых маршрутов.
- Исключение спавна противоположной стороны из поиска командных подходов.
- Seed-варианты пары маршрутов T → A и T → B.
- Оценка расстояния между центрами зон (геометрический прокси).
- Сценарное время только при явно заданной пользователем скорости.
- Тесты для маршрутов и вариантов.

## Ограничения

Расстояние ребра — 3D-евклидова дистанция между центрами зон, не измеренная игровая дистанция. Генератор пока меняет выбор маршрутов, но не двигает зоны и не создаёт новую физическую геометрию. Баланс подтверждается только плейтестами.
