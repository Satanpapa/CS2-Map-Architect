# CS2 Map Architect

Локальная мастерская для проектирования оригинальных соревновательных карт Counter-Strike 2 (5v5, Defuse).

## Исходный код

Полный воспроизводимый снимок проекта (PHASE 1 + текущий срез PHASE 2) находится в архиве:
`CS2-Map-Architect-phase2-source.zip`.

Архив содержит исходный Python-проект, демо-карту `de_quartz`, документацию, автотесты и GitHub Actions workflow. Распакуйте его так, чтобы каталог `cs2-map-architect` стал корнем рабочего проекта.

## Текущая реализация

- MapSpec 1.0 (Pydantic), семантический валидатор и SVG-рендерер.
- Dijkstra: кратчайший маршрут по графу зон.
- Yen: до K кратчайших простых маршрутов.
- Seed-варианты пары подходов T → A и T → B.
- Исключение спавна противоположной стороны из поиска командных подходов.
- CLI для JSON-отчёта и SVG-превью вариантов.
- 85 автотестов.

## Быстрый старт

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
python -m pytest -q
python scripts\generate_demo.py
python scripts\plan_variants.py --seed 2026 --variants 3 --paths-per-site 5
```

## Ограничения текущего PHASE 2

Расстояние ребра — 3D-евклидова дистанция между центрами зон, то есть геометрический прокси, а не измеренная игровая дистанция. Время не рассчитывается без явно заданной пользователем скорости. Генератор меняет выбор маршрутов, но пока не перемещает зоны и не создаёт новую физическую геометрию. Баланс подтверждается только плейтестами.

Подробности: `docs/PHASE_2_REPORT.md`, `docs/ARCHITECTURE.md`, `docs/ROADMAP.md`.

## Безопасность

На этом этапе система не изменяет файлы CS2, Steam или Workshop Tools и не экспортирует VMAP. Интеграция с Hammer остаётся отдельным исследовательским этапом.
