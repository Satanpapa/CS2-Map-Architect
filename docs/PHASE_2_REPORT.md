# PHASE 2 — графовый анализ и варианты маршрутов

Статус: первый функциональный срез реализован; PHASE 2 в целом не закрыта.

## Реализовано
- Dijkstra для кратчайшего маршрута.
- Yen для K кратчайших простых маршрутов без повторного посещения зон.
- Учёт направленных и двунаправленных связей.
- Исключение спавна противоположной стороны при поиске командных подходов.
- Seed-варианты пар T → A / T → B.
- Преобразование варианта в копию MapSpec для SVG-просмотра; исходная карта не мутируется.
- CLI формирует JSON-анализ и SVG-превью.

## Методика и ограничения
Стоимость ребра — 3D-евклидово расстояние между центрами связанных зон. Это геометрический прокси, а не фактическая длина прохода: текущий MapSpec не задаёт двери, центральные линии коридоров или waypoint-траектории. Время не рассчитывается по умолчанию. Если пользователь явно передаёт `movement_speed_mps`, время вычисляется как прокси-дистанция / эта скорость; это не заявление об официальной скорости CS2.

Генератор выбирает маршруты из существующего графа. Он не меняет положения и размеры зон, не моделирует видимость, гранаты, движение игрока или боевую экспозицию. Он не доказывает баланс. Каждый вариант должен оцениваться человеком и тестироваться в CS2.
